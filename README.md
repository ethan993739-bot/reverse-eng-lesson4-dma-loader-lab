# 逆向工程实战课 · 第四课 —— DMA Loader 加载器授权靶场

> 同学们好，我是这门课的讲师。欢迎来到第四课。
> 这一课我们不再纸上谈兵，直接拿一个**真实的 Windows 客户端加载器样本**开刀，
> 带大家走一遍「从拿到样本 → 信息收集 → 静态分析 → 动态分析 → 写出分析报告」的完整流程。

---

## 一、本课目标

本课围绕目录中的样本 `逆向实战课第四课-授权靶场.exe` 展开，学习目标如下：

1. **PE 结构识别**：熟悉样本的文件头、节区（`.text` / `.rdata` / `.data` / 加壳节）、导入导出表。
2. **静态信息收集**：使用 `strings` / PE 工具提取字符串、URL、特征常量，还原样本的基本行为意图。
3. **动态行为分析**：在隔离环境中观察样本的启动流程、子进程、句柄操作与网络行为。
4. **反分析意识**：识别样本中可能存在的检测、环境探测与自我保护逻辑。
5. **产出报告**：按照课堂模板，输出一份结构化分析报告（提交到本课作业区）。

## 三、实验环境准备（务必先做）

1. 准备一台**隔离虚拟机**（推荐 Windows 10/11 x64），**关闭网络或使用独立网段**。
2. 安装分析工具链：
   - 静态：`PE-bear`、`CFF Explorer`、`Detect It Easy (DIE)`、`strings`、`010 Editor`
   - 动态：`Process Monitor`、`Process Explorer`、`API Monitor`、`Wireshark`
   - 调试：`x64dbg` / `x32dbg`、`Scylla`
3. **备份系统快照**，方便实验后一键回滚。
4. 关闭 Windows 实时防护对样本目录的干扰（在**隔离环境内**操作）。

## 四、实验步骤

### 第 1 步：信息收集（Recon）

```powershell
# 1. 提取可见字符串，过滤出 URL / 域名 / 关键词
strings64 "逆向实战课第四课-授权靶场.exe" | Select-String -Pattern "http|\.dll|\.sys|driver|\.exe" | Out-File recon_strings.txt

# 2. 查看文件哈希，作为样本指纹
Get-FileHash "逆向实战课第四课-授权靶场.exe" -Algorithm SHA256
```

### 第 2 步：静态分析（Static）

- 用 **DIE** 查看编译器、是否加壳、是否有 VMProtect / Themida 等保护特征。
- 用 **CFF Explorer** 查看节区名与节区属性，注意是否存在可疑节名（如 `.vmp`、`.themida`）。
- 用 **PE-bear** 观察导入表，重点关注：
  - 进程操作：`OpenProcess` / `CreateRemoteThread` / `WriteProcessMemory`
  - 驱动交互：`CreateFile` 指向 `\\.\` 设备
  - 网络：`WinHTTP` / `WinINet` / `socket`
  - 反调试：`IsDebuggerPresent` / `CheckRemoteDebuggerPresent` / `NtQueryInformationProcess`

> 课堂提问：导入表里同时出现「进程操作 + 驱动设备打开」意味着什么？这暗示样本的哪类行为？

### 第 3 步：动态分析（Dynamic）

1. 在隔离虚拟机中先启动 **Process Monitor**，设置过滤器（按样本进程名）。
2. 以**普通权限**运行样本，观察：
   - 是否释放了额外文件（dll / sys / 临时文件）到磁盘
   - 是否尝试创建服务或加载驱动
   - 是否有网络回连（用 Wireshark 抓包，记录目标 IP / 端口 / 域名）
3. 再用**管理员权限**运行一次，对比两次行为的差异（对应目录里的说明脚本思路）。
4. 记录样本是否检测虚拟机 / 调试器，尝试在 x64dbg 里下断点观察关键 API 调用。

### 第 4 步：写报告

按照课堂模板输出报告，至少包含：样本指纹、保护方式、关键字符串、关键导入、动态行为、网络行为、检测逻辑、以及你的分析结论。
