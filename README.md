## 作业要求

请以参考账号登录时的表现为基准，独立完成以下各项，并逐条给出你的过程与结论：

1. 记录参考账号从登录到点击 Start 之后的完整动作，理清每一步之间是怎么衔接的。
2. 把驱动是怎么被拉起来的过程查清楚，包括服务是怎么建、怎么删、怎么起的。
3. 弄清不同选项用的到底是同一份内核，还是各自一份，给出你的判断依据。
4. 找到选项真正关联的那些资源文件，分析它们是什么样的东西、起什么作用、数据最后流向了哪里。
5. 查清楚程序是怎么尝试和内核通信的，通信到底通不通，不通的话卡在哪一步、差什么。
6. 想办法让整个过程不依赖登录也能走通，把卡住的地方补上，直到整条流程能自己跑完。

任何一步卡住都不要停，继续往下追，目标是把整条流程追到底、改到能独立跑完为止。

## 建议先入手的地方（仅供参考）

- 从查壳和字符串开始，把样本里面的关键词、导入函数摸一遍。
- 边跑边抓服务相关的调用，看它建了什么、删了什么、起了什么。
- 对比不同选项下的行为，找它们之间的相同点和不同点。
- 盯着资源文件的加载和解密过程，看它最终把数据交给了谁。
- 看用户态是怎么打开通信口的，反推为什么没通、应该补什么。
- 找到控制流程走向的那些判断，改一改，观察流程会不会继续往前跑。
