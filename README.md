## 实验目的

1. 观察并记录程序从启动到完成主要动作的完整过程。
2. 理解程序内部各个步骤之间的先后关系和数据流向。
3. 学会用调试工具观察一个程序的真实行为。
4. 能够独立复述「这个程序是怎样工作的」。

---

## 实验内容

请围绕样例程序完成以下观察与分析，并逐条记录你的发现：

1. **启动过程**：用测试账号进入程序，记录从启动到界面就绪之间发生了什么。
2. **内部组件**：观察程序调用或创建了哪些组件（例如服务、文件、通信等），它们各自起什么作用。
3. **数据文件**：找到程序运行时会读取或生成的那些数据文件，分析它们的内容和去向。
4. **通信情况**：观察程序是否与某些组件进行通信，通信是怎样建立的、结果如何。
5. **流程梳理**：把上面观察到的信息串起来，写清楚这个程序「从头到尾是怎么工作的」。
6. **过程复现**：在你自己的环境里把上述流程完整跑一遍，记录过程中遇到的情况和你的处理方式。

实验过程中发现任何现象都不要跳过，如实记录并继续观察下去，直到把整个运行过程完整还原出来。

---

## 观察提示（供参考）

- 可以先了解程序的基本信息和内部字符串。
- 运行时留意程序的各项动作，记录它创建、删除、启动了哪些东西。
- 关注程序读取的文件，尝试理解这些文件在流程中的作用。
- 如果程序尝试和某个组件通信，观察通信是否顺利，中间发生了什么。
- 把每一段流程的先后关系理顺，最终形成一份完整的「程序运行说明」。
