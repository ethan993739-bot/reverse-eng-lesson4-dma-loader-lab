# 逆向工程实战课 · 第四课 —— 加载器样本分析

> 同学们好，我是这门课的讲师。前几课我们熟悉了工具和调试方法，这一课换个节奏：
> 我会给你一个**受保护的真实样本**，不预设结论，由你自己把它分析清楚、讲明白，
> 并用动手修改的方式验证你的判断。分析过程本身就是这节课的重点。

---

## 一、样本信息

| 项目 | 内容 |
| --- | --- |
| 样本文件 | `逆向实战课第四课-授权靶场.exe` |
| 样本类型 | Windows 客户端加载器 |
| 已知信息 | 样本经过 **VMProtect** 加壳，内部存在一段**驱动加载**相关的逻辑 |

关于这个样本的结构、行为与保护细节，课程不提供现成答案，需要你亲手分析得出。

---

## 二、学习目标

1. 掌握对加壳样本的分析思路，从查壳一步步走到还原关键逻辑。
2. 还原样本的完整加载流程，尤其是其中与驱动加载相关的那一段。
3. 理清样本内部各类条件判断的作用与触发时机。
4. 学会用「修改样本 → 观察行为变化」的方法，验证自己对加载流程的理解。

---

## 三、分析任务

围绕样本，完成以下几件事，方法与工具由你根据实际情况自行选择：

1. **信息收集**：确认样本的壳类型、节区结构、导入函数，提取可用字符串。
2. **行为梳理**：观察样本启动后做了什么，驱动加载逻辑在什么条件下会走到。
3. **定位关键判断**：找到影响驱动加载是否执行的那个条件分支，弄清它的判定依据。
4. **动手验证**：对样本做局部修改，观察驱动加载逻辑在不同条件下的行为变化，
   据此验证你对加载流程的理解是否正确。
5. **产出报告**：把分析过程、结论与验证结果整理成一份报告。

> 提示：本课的重心是「读懂加载流程并验证理解」，修改样本只是验证手段，不是目的。

---

## 四、可参考的方向（仅供参考，不必照搬）

- 先做信息收集：字符串、节区、导入表、样本指纹。
- 观察运行行为，重点关注与驱动、服务、设备交互相关的部分。
- 针对 VMProtect 尝试脱壳或反虚拟化，还原关键逻辑。
- 找到控制驱动加载的那条分支后，尝试修改并观察行为变化。
- 全程记录「改了什么、为什么改、改完效果如何」。

---

## 五、报告要求

- 格式：Markdown 或 PDF。
- 内容至少包含：
  1. 样本保护的识别与分析
  2. 驱动加载逻辑的定位过程与结论
  3. 修改记录（地址 + 原始字节 + 修改后字节）与行为对比
  4. 验证截图与最终结论
- 加分项：写一段你对这类保护的加固与防御思考。
